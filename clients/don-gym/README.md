# Arch Training — Client Engagement

First paid customer of the AI Agency. **Arch Training** is a 3-location NJ gym
(Eatontown, Freehold, +1), owner Don (Domenick Cilea). The engagement converts a
warm consulting opening into a scoped, repeatable growth-strategy deliverable.

All assets for this client live here. This is the single source of truth —
local research, strategy decks, and the rendered pitch microsite (pulled from
GCS) are consolidated in one folder.

## Brand snapshot

Extracted from the live Squarespace site (`research/brand-visual.md` has the full breakdown).

- **Palette:** near-black base (`#000000` / `#131313` / `#1f2526`), pure white text
  (`#ffffff`), single signature accent **deep crimson `#a21e22`**. Classic dark-gym look.
- **Client site fonts:** Europa (display/headings), Calluna (serif body),
  Proxima Nova (UI/buttons).
- **Pitch-site fonts:** Inter + Oswald (Google Fonts) — the approximation used in
  the rebuilt microsite, not the licensed site fonts.
- **Logos:** `research/logo-*.png` (ink-red, white-transparent, dark-transparent,
  black-bg variants).
